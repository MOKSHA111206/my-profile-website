# Personal Profile Website

A responsive static personal portfolio built using HTML and CSS.

## Files
- `index.html` — website content
- `style.css` — styling and responsive layout

## Run locally
Open `index.html` in any web browser.

## Publish with GitHub Pages
1. Create a new **public** repository on GitHub (for example, `my-profile-website`).
2. Upload `index.html`, `style.css`, and this `README.md` to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. After deployment, your website URL will look like:
   `https://YOUR-GITHUB-USERNAME.github.io/my-profile-website/`

Before publishing, add your preferred email and profile links in the Contact section and verify the displayed name and project details.
